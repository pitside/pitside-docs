# Pitside Documentation

## Getting Started with VitePress

### Prerequisites
Before you begin, ensure you have the following installed:
- [Node.js](https://nodejs.org/en/download/) (version 12 or later)
- npm or yarn (package managers)

### Installation
1. Clone the repository:  
   ```bash
   git clone https://github.com/pitside/pitside-docs.git
   cd pitside-docs
   ```

2. Install the dependencies:  
   Using npm:  
   ```bash
   npm install
   ```  
   Or using yarn:  
   ```bash
   yarn install
   ```  

### Running VitePress
To start the development server, run:  
```bash
npm run docs:dev
```

Visit [http://localhost:3000](http://localhost:3000) in your browser to see your VitePress site.

### Building the Documentation
To build the static site for production, run:  
```bash
npm run docs:build
```

The generated files will be located in the `dist` directory.
